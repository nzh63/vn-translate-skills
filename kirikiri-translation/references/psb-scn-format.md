# PSB / .scn 剧本格式与字符串回写

> 适用：KAGParserEx 等编译产物 `.scn`（"mdf" 容器 + PSB v3）。
> 工具：`scripts/psb_tool.py`（json / strings / rebuild / verify）。

## 1. 容器与整体布局

```
.scn = "mdf\0" + u32(解压大小) + zlib(PSB)     （也有游戏直接存裸 PSB）
PSB v3:
  头 0x2C: u32 版本@4, 字符串偏移表@0x10, 字符串数据@0x14, chunks@0x18, chunkdata@0x1C, entries@0x20 ...
  Names 段: Charset / NamesData / NameIndexes 三个数组（字典键的前缀压缩编码，算法同 FreeMote LoadNames）
  Objects 树: 剧本结构（scenes[].lines / texts 等）
  字符串偏移数组 + 字符串数据区(UTF-8, NUL 结尾, 首串为空串)
  尾部两个空数组块
```

## 2. 定宽数组的自描述宽度标记（★最大坑）

PSB 数组头 = `[计数宽度标记][计数][元素宽度标记][元素...]`，标记 `0x0D` 起每 +1 代表
**字节数 +1**：

| 标记 | 元素字节 |
| --- | --- |
| 0x0D | 1 |
| 0x0E | 2 |
| **0x0F** | **3（不是 4！）** |
| 0x10 | 4 |

字符串偏移数组的宽度按数据区大小自适应：≤64KB 用 `0x0E`(u16)，更大的用 `0x0F`(3 字节)。
**回写时标记与实际字节宽必须一致**——曾因"0x0F 配了 4 字节元素"导致整个字符串表错位、
引擎加载即崩，且树区校验（tree-end MATCH）完全查不出来。重建后必须做内容级验证（§5）。

## 3. 双副本机制：显示版与履历版

KAGParserEx 的消息文本在字符串表中全局去重，一条多行对白通常占**两个条目**：

- **显示版**：含字面换行记号 `\n`（反斜杠+n 两字符）→ 消息窗逐行显示；
- **履历版**：同一原文去掉记号的副本 → 待避/既读判定/履历（backlog）共用。

两者被同一条 texts 记录引用。因此**只翻译显示版**，履历版由回写器自动派生
（译文去掉 `\n` 记号写入对应条目）；短句（无换行）只有单一字符串。
若目标引擎无此机制，派生步骤自然空转，无害。

## 4. 回写流程（原文件只读）

1. 读原表 → 按 TSV 索引替换内容；**索引越界或日文原文不符立即拒绝**（防错位）。
2. 含真实换行符的译文直接拒绝（必须写字面 `\n` 记号——命令行/表格软件常把它解码成
   真实换行，写完按"数据行 tab 数"扫描一遍）。
3. 派生履历版（可 `--no-backlog` 关闭）。
4. 重排字符串数据区：偏移数组按 §2 选宽度；表序与数量不变，树区字节零改动；
   更新头部 @0x14/@0x18/@0x1C/@0x20 四个偏移字段。
5. 按原容器形态输出（保持 mdf 或裸 PSB 包装）。

## 5. 验证门禁（封包前必过）

`psb_tool.py verify <orig> <new> <tsv...>` 做**内容级**比对：

- 新文件每个字符串 == 「原表 + TSV 生效译文 + 派生履历」的预期结果；
- ASCII 结构串（标签名、文件名、数字参数等）零改动；
- 字符串数量不变；树可完整解析。

⚠ 只验"树区结尾对齐"或"能解出 JSON"是**不够的**——字符串表错位时树照样解析成功。
凡改动验证/回写逻辑，先用已知样本回归，再上真机。

## 6. 文本定位（生成翻译模板）

顶层 `scenes[*].texts` 是按剧情顺序的消息表，条目形如：

```
[说话人(str|null), [[null, "显示文本", 字数, 履历副本?, ...]], 语音信息|null, 字数, 环境...]
```

- 显示文本在 `entry[1][j][1]`；说话人标签在 `entry[0]`（空 = 旁白/独白，多为第一人称内心，
  是翻译语气的重要依据）。
- 部分剧本还有大量**不经 texts 表、由 lines 直接引用**的对白/短句——只按 texts 提取会漏，
  可读文本到某句戛然而止往往就是这个原因。兜底：`psb_tool.py strings` 全量导出人工甄别，
  或 `make_template.py --all`。
- 引擎硬限制（每行字数 × 行数，典型如 27×3）逐作不同：进游戏实测或查引擎代码校准，
  再用 `validate_text.py --width= --lines=` 固化成门禁。
